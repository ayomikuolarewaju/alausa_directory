# Alausa Directory

A civic information directory for Lagos State — built on the view that public information only helps people if they can actually find it.

🔗 **Live:** [alausadirectory.com](https://alausadirectory.com/)

## What it does

Gives Lagos residents a single place to find and navigate Lagos State government: ministries, agencies, local governments, and their functions.

## Features

- **Government directory** — coverage of Lagos State ministries, agencies, LGAs, and LCDAs
- **Transport info** — live public transport coverage sourced from LAMATA
- **News aggregation** — local news pulled in automatically via RSS feeds
- **SEO-first** — full metadata, sitemap, and AdSense setup from the start, since discoverability is the whole point of a directory

## Tech stack

- **Framework:** Next.js, TypeScript
